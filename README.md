# Gestock Pro — mises à jour

Ce dépôt sert de serveur de mises à jour pour Gestock Pro.

- `latest.json` : la dernière version (numéro, fichier, taille, empreinte SHA-256, nouveautés).
- `versions/` : les installateurs Windows.

Adresse à mettre dans Gestock Pro (poste serveur → Paramètres → Mise à jour) :

```
https://raw.githubusercontent.com/ounisnounou/gestock-pro-mises-a-jour/main/latest.json
```
